# 易混词索引

以下内容来自“英语易混词速查表”，按辨析关系整理。后续新增词汇会继续并入对应词组，而不是按日期另建文件。

## 词义或词形相近

- `tuition` / `intuition`：学费、教导 / 直觉。
- `spear` / `shear`：矛 / 剪、剪羊毛。
- `flutter` / `flatter`：振翅、飘动 / 奉承。
- `rational` / `radical`：理性的、合理的 / 激进的、根本的。
- `capital` / `capitalism`：资本、资金 / 资本主义。
- `speculate` / `spectacular` / `spectacle`：推测、投机 / 壮观的 / 奇观。
- `excursion` / `incursion`：远足 / 侵犯、入侵。
- `eternal` / `internal`：永恒的 / 内部的。
- `commission` / `concession`：委托、佣金 / 让步、特许权。
- `assess` / `access` / `reassess`：评估 / 进入、使用权 / 重新评估。
- `eligible` / `negligible`：符合条件的 / 微不足道的。
- `volatile` / `versatile`：易变的、易怒的 / 多才多艺的、多用途的。
- `confine` / `refine`：限制 / 改进、精炼；`be confined to` 后接 `to`。
- `resemble` / `assemble`：像 / 集合、组装。
- `diplomat` / `diploma`：外交官 / 文凭。
- `contemporary` / `temporary`：当代的 / 暂时的。
- `integrity` / `integrate` / `integration`：正直、完整 / 融合 / 整合。
- `assume` / `presume`：无充分证据的假定 / 基于依据的推定。
- `trait` / `strait`：特征 / 海峡；狭窄、严格。
- `retort` / `refute`：带情绪地反驳 / 正式地驳斥。
- `prelude` / `preclude`：前奏、序幕 / 排除、妨碍。
- `proposition` / `preposition`：提议、命题 / 介词。
- `concept` / `conception`：概念 / 构想、理解、受孕。
- `coarse` / `hoarse`：粗糙的 / 嘶哑的。
- `yield` / `wield`：产出、屈服 / 运用、挥舞。
- `deprive` / `derive`：剥夺 / 源自；`derive from`。
- `inferior` / `interior`：较差的 / 内部的。
- `proximity` / `vicinity`：接近、邻近 / 附近地区。
- `amplify` / `ample`：放大、增强 / 充足的。
- `breach` / `preach`：违反、破坏 / 布道、说教。
- `unilateral` / `multilateral`：单边的 / 多边的。
- `inherit` / `inhibit`：继承 / 抑制、约束。
- `prone` / `prose`：易于……的、俯卧的 / 散文。
- `conscientious` / `contentious`：认真负责的 / 好争论的、有争议的。
- `menace` / `senate`：威胁 / 参议院、上议院。
- `syndicate` / `synthetic`：企业联合体 / 合成的、人造的。
- `scramble` / `shamble`：争抢、攀爬 / 蹒跚、拖沓。
- `obedient` / `obese`：顺从的 / 肥胖的。
- `comparable` / `compatible`：可比较的、类似的 / 兼容的、合得来的。
- `nominate` / `nominee`：提名、任命 / 被提名者。

## 记忆方法

不要只背中文对应词。比较每组词的词性、搭配和典型语境，并各写一个自己的例句；遇到新词时优先查找它是否能和已有词形成易混组。
