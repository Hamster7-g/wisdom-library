# 智慧库

> 一个用 Markdown 写成的个人知识库。内容多为**自己提炼的可执行做法**，而不是收藏的资料堆积。

每张卡片都尽量回答四个问题：这是什么、为什么有效、具体怎么做、什么时候**不**适用。

---

## 快速开始

### 三种找东西的方式

| 你想做的事 | 怎么做 |
|---|---|
| 知道大概在哪个分类 | 打开 [`90_索引/总索引.md`](90_索引/总索引.md) |
| 只记得一个关键词 | 终端跑 `python tools/search.py 关键词` |
| 只记得一个标签 | 终端跑 `python tools/search.py 标签名 --tag` |

### 检索工具

无第三方依赖，Python 3 直接跑：

```bash
python tools/search.py 呼吸              # 全文搜索（标题、正文、标签）
python tools/search.py 微技能 --tag      # 标签精确匹配
python tools/search.py 箱式 --list       # 列出全部 81 个标签及篇数
python tools/search.py --stats           # 各分类卡片统计
python tools/search.py 情绪 -c 01_身心健康  # 限定分类搜索
```

### 重新生成索引

新增或修改卡片后刷新索引（索引由脚本生成，不要手工编辑）：

```bash
python tools/build_index.py
```

## 为什么要两层结构

**目录管「是什么」，标签管「怎么找到」。**

同一条知识往往横跨多个分类——「箱式呼吸」既是情绪工具也是身体调节法，「微型休息」既是休息方法也是专注方法。
如果只靠目录分类，同一类内容会被切碎在不同文件夹里，越整理越难找。

所以：

- **目录**只做粗粒度归属，保证浏览时的确定性
- **标签**做横切聚合，一条卡片可以有任意多个标签
- **索引**把两个维度接上：既能从分类找到，也能从标签反查

`90_索引/标签索引.md` 按出现频次分成高频（3 篇以上）、中频（2 篇）、低频（1 篇）三档，
高频标签基本就是这个库当前的知识主干。

## 卡片格式

文件名：`YYYY-MM-DD_主题_简短标题.md`

日期只记录来源时间，**不作为分类依据**。

```markdown
# 标题

## 来源
- 作者 / 出处 / 日期 / 原始文件

## 一句话总结
用一句话说清楚这条知识是什么。

## 核心观点
为什么有效，背后的道理。

## 对我的启发
它和我的生活怎么接上。

## 可以实践的小动作
至少留一个能立刻执行的小动作。

## 适用场景
什么时候用得上。

## 边界与提醒
什么时候**不**用，有什么风险。身体不适时不要硬撑。

## 标签
#标签1 #标签2 #标签3
```

字段顺序固定，`build_index.py` 依赖 `## 一句话总结` 和 `## 标签` 两个小节提取信息。

### 整理原则

- 同一主题的新内容**合并或互相链接**，不按日期拆散。
- 不只保存信息，要提炼成可复用的判断。
- 不把作者观点当真理，保留适用条件和局限。
- 尽量转化为自己的语言。
- 每篇材料至少留下一个可以实践的小动作。
- 标签是横切维度，不受目录限制；判断不准时，宁可多加一个标签也不要新建目录。
